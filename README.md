# Grade3 - 教材與筆記整理專案

本專案主要用於整理三年級（Grade 3）相關課程教材、學習筆記與相關文件資料。

---

## 📁 專案結構 (Project Structure)

```text
Grade3/
├── 31.pdf             # 教材 / 參考資料 PDF
├── F.pdf              # 教材 / 參考資料 PDF
├── README.md          # 專案說明文件
├── progress.md        # 專案進度與待辦事項清單
├── CHANGELOG.md       # 專案變更紀錄
└── .gitignore         # Git 忽略規則
```

---

## 🎯 專案目標

1. **資料彙整**：系統化整理 PDF 教材與學習資料。
2. **筆記歸檔**：建立結構化筆記與主題索引。
3. **進度追蹤**：透過 `progress.md` 追蹤教材讀取與整理進度。

---

## 🛠️ 開發與維護指南

- **新增文件**：請依主題建立目錄放置相應筆記與檔案。
- **變更紀錄**：重大調整請更新 `CHANGELOG.md`。
- **任務更新**：完成階段性任務時同步更新 `progress.md`。
